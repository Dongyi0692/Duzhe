# 渡者 · R03 UI 设计与实现规范

版本：R03-1.0.0　｜　日期：2026-10-27　｜　状态：资源方生成、静态检查完成；引擎接入与交互实测待 Codely。

## 设计目标

沿用 R02 已确认的冷灰蓝像素边框与安静气质。文字用中文字体实时显示；背景或人物不会烘焙到界面皮肤。主菜单之后复用正式冥河背景 BG02_River；随包预览中的平面底色和机关示意不是正式游戏背景或机关素材。

## 范围与结构

UI_Layout.json 给出 25 个 screenId、182 个 controlId。每个控件包含 rect、textKey、action、visibleWhen；动态控件 textKey 为 null 时，按 textBinding 或 dataSource 读取，不得在游戏里显示 null。action 是接入动作名称，不是可执行脚本。

覆盖主菜单、探索目标/互动、对白、暂停/音量、设置、已通关章节、已看过的回忆及回放、渡河说明/航行/失败、离开与重玩/退出确认、拐杖/爱心/再见描画、三凳拖放、合照拖放、门环与七音、制作名单、结尾、存档错误。

UI_Wireframes.html 为位置线框，UI_Overview.html 为设计预览；Previews/Static 为使用本批图形与字体渲染的静态界面图。预览只演示布局与文字，不控制游戏存档或完成机关。

## 画布、坐标和缩放

- 基准 1280×720；rect=[x,y,width,height]，原点左上，x 向右、y 向下。
- 建议 CanvasScaler = ScaleWithScreenSize，referenceResolution=(1280,720)，MatchWidthOrHeight=0.5。1920×1080同为16:9时放大1.5倍，非16:9需在游戏里验证不裁切。
- 左上锚点转换：anchorMin=anchorMax=(0,1)，pivot=(0,1)，anchoredPosition=(x,-y)，sizeDelta=(width,height)；若采用其他锚点，应保证最终参考坐标一致。
- 画布控件层级：世界/HUD < 对白 < 机关/渡河弹窗 < 菜单子页 < 暂停 < 确认 < 存档错误。最上层模态面板屏蔽下层点击与移动，退出清理临时面板及监听。
- 文本优先 24–32 参考像素；正文28并允许3行；主标题72；次要提示20–22。文本框应使用换行，不能溢出或覆盖按钮。237条R01对白通过当前静态尺寸检查，但实际引擎排版仍需再次验证。
- Buttons、Slider、DragSource、DropTarget、InteractionArea 在基准尺寸下均至少 44×44；32×32 是图标画布，不是点击范围。输入顺序：最高模态层 > 暂停 > 机关/对白 > 世界；关闭或切换时消费触发按键、鼠标事件。

## 皮肤与边距

| assetId | PNG实际尺寸 | 九切片边距 Left/Top/Right/Bottom | 用途 |
|---|---|---|---|
| UI01_DialoguePanel | 256×96 | 12/12/12/12 px | 底部对白 |
| UI01_GenericPanel | 192×192 | 12/12/12/12 px | 暂停、说明、机关、确认 |
| UI01_Button | 160×48 | 8/8/8/8 px | 按钮常态 |

三图都是 RGBA PNG，外部和切角有真实透明像素，面板本体为不透明；不是棋盘格。Image Type 设 Sliced、中心填充，边框按上表设置；注意 Unity Sprite Editor 的边距字段顺序，按字段名填写。Point、Mip Map 关闭、无损或不压缩。UI sprite 可按 Canvas 100 reference pixels per unit 配置；世界对象仍按既定32 PPU，最终以导入显示为准。

5 个图标 UI02_Interact、UI02_Item、UI02_Pause、UI02_Volume、UI02_Continue：各 32×32 RGBA，图形大约留4像素透明边距。请复用同名稳定 ID。按钮 normal/hover/focused/pressed/disabled 由 UI_Layout.json 的 buttonStates 及引擎交互状态控制，不额外生成五套位图；键盘焦点需保持可见的暖米色描边。

## 屏幕行为

- 主菜单按钮根据进度使用 menu.start / menu.continue / menu.replay_first；显示存档说明。开始画面复用冥河，初次进入不泄露未完成章节。
- 探索目标来自当前正式 stageId 的 R01 objective；互动提示仅在对应阶段与范围允许时显示。道具提示图标仅用于道具类提示。
- 对白显示说话人、完整当前句和继续提示；点击区域或空格每次推进一条。关闭该次输入不可触发身后物体。
- 暂停界面保留主/音乐/音效三条滑杆；ESC 切换暂停，暂停时保存并恢复此前输入模式，焦点回来后仍保持暂停。未完成章离开必须二次确认。
- 已通关章节列表只读 CH01–CH05 中 completedChapterIds；忽略 CH01_DEV。回忆馆只读实际播放完的 unlockedPresentationIds；空列表展示既定友好文案，不显示未解锁名称。
- 河流说明确认后才计时；失败只重渡河，说明面板不重复；不要出现计时数字/血条。暂停与确认必须遮挡底层按钮，离开时清除河流界面。
- 描画画布为 640×360 设计位，允许抬笔；“再见”按笔画引导、只重画当前笔画，不显示对白空格继续提示。
- 3 把等价凳子分别落到空目标位置，错放回原处、正确锁定；合照仅鼓手可拖到唯一空位。
- 门第一击进入特写，第二击点击门环才敲门，不能同一次点击穿透。七音的1–7数字、音名及下一音高亮同时显示，错误不清空进度，不靠声音作为唯一提示；演奏默认开启。14音是开发示例，最终按 R15 的 CFG_Notes.json。
- 描画、门环、凳子和照片位置是 R03 当前设计建议。C03 若已给出真实坐标，应由 Codely 将两边对齐后更新记录，不能让美术静默改变任务步骤。

## 文本及字体

201条现有文本原样复用 Text/TXT_UI.json；本批新增三条，独立存于 UI_TextAdditions.json：r03.notes.play_demo、r03.notes.progress、r03.trace.progress。合并时按照 key 查重，保留现有值和占位变量 {count}/{total}/{current}，禁止用示例参考 JSON 覆盖游戏数据。UI_Copy_Reference.json 仅用于预览和核对，不能直接作为第二份运行数据自动加载。旧项目下划线 UI key 与正式点号 key 的映射由 Codely 接入层处理。

UI03_Font 为 Noto Sans CJK SC Regular，官方来源、版权字段和 OFL 1.1 原文见 Fonts/FONT_SOURCE.md 与 Fonts/OFL.txt。字体不由图像生成。制作名单中作者署名仍由用户最终填写。

## 操作与状态

- 键盘焦点：页面打开时记录默认焦点；方向键/Tab 在当前模态层内移动；确认键只触发当前可操作控件；ESC 按规范返回或暂停。
- hover 提亮；focused 显示独立的米色描边；pressed 有轻微暗化；disabled 降低对比且不可触发。不能只用颜色区别关键状态，七音还显示明确数字和音名。
- 按住鼠标拖动时禁用角色移动，暂停期间不触发机关；未完成拖拽回原位置，再继续可操作。
- 关闭面板应销毁或复用其专属对象、移除监听并恢复上一层焦点，禁止覆盖常驻 EventSystem。
