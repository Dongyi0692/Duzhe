# R03 接入给 Codely（一页）

1. 解压到源资源归档；按现有工程组织导入 UI/Skins 的3张PNG、UI/Icons的5张PNG与 UI/Fonts/NotoSansCJKsc-Regular.otf。保留字体版权与 Fonts/OFL.txt。替换已有正式资源时保留 .meta；不覆盖开发目录之外的用户文件。
2. 按 UI_Layout.json 的1280×720左上坐标与 UI_Design.md 的九切片边距装配。世界仍32PPU；UI使用画布参考像素。当前 C03 机关热点坐标若与设计不同，先核对 C03 实际交接，再调整布局并记录，勿改玩法。
3. 对照已暂存的R01 TXT_UI.json，将 UI_TextAdditions.json 中3个新键唯一合并到正式UI数据；UI_Copy_Reference.json 仅供预览核对，不作为第二份自动加载数据。原有下划线键在适配层映射正式点号键，变量由运行时填充。
4. 实现并检验：章节仅正式已完成ID，回忆仅已播放完ID；暂停/确认最上层并阻止点击穿透；失败仅重渡；描画不可显示空格继续；七音默认开启且数字、文字与高亮均可见；对话逐句手动推进。
5. 游戏中以1280×720、1920×1080检查字体导入、最长对白、按钮/焦点、图标、弹窗遮挡、九切片边缘、缩放，以及各机关真实绘图区。导出实际已测/未测和 CodelyHandoff.md。此包中的静态预览不代表引擎测试通过。

重要纠正：最近C02交接有“暗橙暖色阴间/伪三维混合俯视/32×48×4帧/5色板”的文字，与已批准R02不符。请以本包 Style/StyleLock.md 为准：阴间冷灰蓝且清晰、统一俯视2D；渡客稍浅灰蓝、脸和眼睛可见；行走表3列×4行，每帧32×48，行Down/Left/Right/Up、列WalkA/Idle/WalkB；色值是起点，并非只能用5色。不要根据旧表述修改已确认画风。
