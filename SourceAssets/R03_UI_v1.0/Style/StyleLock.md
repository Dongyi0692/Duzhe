## 1. 这张图用来确定什么

确定冷暖关系、俯视构图、人物服装与剪影、任务物辨识度、对话框的整体气质。阴间是安静而略带疏离感的渡口，冷但不恐怖；故事仍以现代普通人的牵挂为核心。

样板中的两人分别是 Ferryman（渡客）和 Grandmother（奶奶）；眼镜属于奶奶，所以她脸上不再戴另一副眼镜。其他角色仍按正式剧本生产。

这是合成的视觉参考，不是可直接导入的 BG01_Underworld、角色图集或 UI01_DialoguePanel。图中台阶、树、船和灯只是构图示意，不新增互动点或任务；正式关卡位置由 R04 布局确定。

## 2. 视角与比例

- 俯视二维 RPG：能看见头顶与人物正面，地面有充足可走空间；不用地平线、透视消失点或侧视平台画面。
- 建筑、码头与室内布局按屏幕横纵方向组织，不做等距菱形地图。树和石块可有自然轮廓。
- 角色采用约 2.5 头身的紧凑比例；渡客兜帽计入头部外轮廓。奶奶略矮，头部与其他角色保持同一尺度。
- 正式角色单帧 32×48，身体连头顶和鞋底均不超出画布。以脚底中心 pivot=(0.5,0) 对齐，每帧一致。
- 世界参考视口 640×360，32 PPU。正式背景 1280×720，允许相机跟随；不要用本样板的角色与地图相对位置生成碰撞或触发器。

## 3. 人物识别

| 对象 | 固定方向 |
|---|---|
| Ferryman | 中等偏暗的低饱和灰蓝外衣与短披肩，小圆兜帽敞开，浅色内领、深色裤鞋；年轻面孔清楚可见，眼睛不被帽檐或阴影挡住。取消长围巾及臃肿外套；手臂自然垂下，空手。以克制配色、安静表情和简洁剪影保留神秘感，不靠遮脸或阴暗表达。 |
| Grandmother | 灰白盘发，灰紫/藕色日常开衫，浅内搭，深色裤子与平底鞋；面部温和，使用少量像素表示。 |
| Reading glasses | 一副双镜片眼镜，清楚的镜框与镜腿；放在较浅、纹理少的地面上，深轮廓与小亮点辅助识别。正式资源单独交透明图。 |

衣物、发型与配色沿用本样板，四向动作必须参考已确认单帧。不从文字重新随机设计同一角色。现代中国日常服饰原则同样适用于其余人物。

## 4. 像素与轮廓

- 后续正式素材使用可辨认的方形像素块，减少碎石、布料与树叶的细碎噪点。
- 角色与可交互道具以约 1 个逻辑像素的深色外轮廓为基准。轮廓不能在放大生成图中直接按 1 个实际像素套用。
- 每类材质优先 2–3 级明暗，不用油画笔触、写实材质或强烈渐变。
- 角色阴影小而贴近脚底，不让背景阴影遮掉鞋底；动态角色阴影后续由 Codely 统一处理，防止叠出双重阴影。
- 最终尺寸下重新检查人物脸、手和眼镜辨识度；样板不能直接缩小或裁出来当生产素材。

## 5. 色彩与光

以下为规范起始色，不是从图片提取的精确色卡；生成图存在更多过渡色。

| 用途 | 起始色 |
|---|---|
| 阴间深色、水与界面底 | #263544 深蓝灰 |
| 中间冷色、远处环境 | #718596 雾蓝 |
| 边缘与冷色亮部 | #B7C5CC 浅灰蓝 |
| 地面与微量暖光 | #D7BC8D 米色 |
| 码头与木材 | #795845 木棕 |
| 阳间植物参考 | #7D9778 柔绿 |

阴间地面比渡客外衣更亮，以明度差确保人物可见。浅雾局限远处和边缘，正式背景可分层，不能盖住任务物与路径。暖光少量点缀，不新增点灯玩法。阳间四个空间按各自自然色彩生产，不继承全屏蓝灰滤色。

## 6. 背景与 UI

- 环境纹理的对比度低于人物和任务物；在交互点周围留较安静的地面。
- 正式背景不包含可交互人物、眼镜等任务物、可拖道具或界面。船等交互对象也按对应资源单独制作。
- 对话框位于屏幕底部，约占屏高五分之一，四边留边距；深蓝灰底，细浅灰蓝边框，轻微阶梯角。
- 正式 UI 由 R03 单独制作可拉伸面板，生成图中的底色过渡不作为必须复制的效果。
- 中文对白、姓名、按钮标签由引擎清晰渲染，不烘焙进图片。UI 参考分辨率 1280×720，正文建议 28–32，最终按实机换行与阅读距离调整。
- 无血条、攻击按钮、可见渡河倒计时，不增加原规范以外的 HUD。

## 7. 实际文件与生产边界

VisualGuide.png 实测为 **1672×941、RGB、不透明 PNG**，约 16:9。图像生成工具没有按请求输出 1920×1080；没有为凑尺寸进行拉伸、裁切或重采样。

该图是高分辨率像素风参考，未证明严格锁定 640×360 的统一像素网格。它不能作为32×48角色或1280×720背景的像素精度验收依据。正式资源必须另行检查尺寸、透明通道、轮廓和切片；Codely处理必要的确定性导入，不靠放大缩小样板凑成品。

导入正式世界素材时使用 Point、关闭 Mip Map、不压缩或无损，透明图检查真实 Alpha。对本样板无需进行游戏资源导入。
